# SUMMER QUEST 🛡️ — 夏休みミッション記録アプリ

子供の夏休みの生活改善を目的とした、カレンダー型のTODO（日報）アプリです。
毎日のミッション（勉強・運動・プール・タイピング・ゲーム・習い事・ふりかえり）を記録すると、カレンダーに〇が付き、努力の積み上げがグラフと**六角形ステータス**で見える化されます。

### ログイン（親子で分かれています）

- **子アカウント**（お子さん用）：ID `びゃくれん` ＋ パスワード `0228`
  - 見られるのは「カレンダー」と「せいせき」だけ（設定は表示されません）
- **親アカウント**（おうちのひと用）：**IDは空っぽのまま** ＋ パスワード `0612`
  - こちらだけ「せってい」が表示されます（夏休み期間・タイピングURL・Firebase・バックアップ）

> アカウントの切り替えは、画面右上の名前（👤 ⏻）をタップ → ログアウトして切り替えます。

## 1. まずはそのまま使う（設定なしでOK）

`index.html` を **ダブルクリック** するだけで、Chrome などのブラウザで動きます。
この状態ではデータは「そのパソコンのブラウザ」に保存されます（＝端末保存）。

> ⚠️ 端末保存のときは、ブラウザの履歴・キャッシュを消すとデータが消えます。
> 「せってい → バックアップ → 書き出す」で、ときどきファイルに保存しておくと安心です。

## 2. クラウド保存（Firebase）にする ＝ 複数の端末で同期

ご希望の「Google（Firebase）でクラウド保存」にする手順です。無料の範囲で使えます。

### 2-1. Firebaseプロジェクトを作る
1. [https://console.firebase.google.com/](https://console.firebase.google.com/) にGoogleアカウントでログイン
2. 「**プロジェクトを追加**」→ 名前（例：`summer-quest`）を入力して作成
3. Googleアナリティクスは「無効」でOK（有効でも可）

### 2-2. Firestore（データベース）を作る
1. 左メニュー「**構築 → Firestore Database**」→「**データベースを作成**」
2. モードは「**テストモードで開始**」を選ぶ（あとで変更できます）
3. ロケーションは `asia-northeast1（東京）` を選んで作成

### 2-3. ウェブアプリを登録して「設定」を取得
1. プロジェクト設定（⚙️歯車アイコン）→「**全般**」タブ
2. 「マイアプリ」で **`</>`（ウェブ）** アイコンをクリック
3. アプリ名（例：`summer-quest`）を入れて登録
4. 表示される `firebaseConfig` の中の次の値をメモ：
   - `apiKey`
   - `projectId`
   - `appId`（任意）
   - `authDomain`（任意）

### 2-4. アプリに入力する
アプリを開いて「**せってい → クラウド保存（Firebase）**」に、上でメモした値を貼り付け、「**せっていを保存する**」を押します。
保存さきの表示が「**クラウド（Firebase）**」に変わればOKです。

### 2-5. 保存ルール（大切）
テストモードは約30日で読み書きできなくなります。ずっと使うには、Firestoreの「**ルール**」タブを開いて次のようにします。

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
```

> 🔒 このアプリはID/パスワードが固定の簡易ログインのため、ルールを `true` にすると
> 「公開URLとFirebase設定を知っている人なら誰でも読み書きできる」状態になります。
> 記録内容は勉強ログなので大きな問題にはなりにくいですが、気になる場合は
> **端末保存のまま使う**のが最も安全です。

## 3. インターネットに公開する（GitHub Pages）

「ギットの公開」＝GitHub Pages で無料公開できます。

1. [https://github.com/](https://github.com/) でアカウントを作る（無料）
2. 「New repository」で新しいリポジトリを作成（例：`summer-quest`、Public）
3. `index.html` をアップロード（「uploading an existing file」からドラッグ＆ドロップ→Commit）
4. リポジトリの「**Settings → Pages**」を開く
5. 「Build and deployment」の Source を「**Deploy from a branch**」、Branch を「**main / (root)**」にして Save
6. 1〜2分待つと `https://（ユーザー名）.github.io/summer-quest/` で公開されます

> 公開URLをお子さんのパソコンのブラウザで「お気に入り」に登録すれば、毎日すぐ開けます。
> クラウド保存（Firebase）にしておけば、別のパソコンからでも同じ記録が見られます。

## 4. 設定でカスタマイズできること

「**せってい**」画面から、いつでも変更できます。

- **夏休みの期間**（残り日数カウント用）：初期値は `2026-07-21` 〜 `2026-08-31`
- **タイピングゲームのリンク（URL）**：**「こどもタイピング」** に設定済みです（`https://typing.twi1.me/game/3880`）
  - 日報の「タイピング」欄の「▶ こどもタイピングで あそぶ」ボタンから開けます
  - 別のゲームに変えたいときは、このURL欄を書き換えてください
  - **じょうけん**欄に「毎回のやり方」を書いておくと、同じ条件でスコアを比べられます
- **タイピングゲームの名前**：ボタンに表示される名前

## 5. こだわりポイント

- **ダーク×シルバー×サイバー**調で、こどもっぽくないゲームUI
- **遅れると警告**：1日記録がないと画面が**黄色**、2日以上で**赤**に光って知らせます
- **祝日を自動表示**（祝日API `holidays-jp` を利用）
- 言葉づかいは**小学3年生**を基準（AIコーチの返事も同じ基準。漢字は小1〜3の440字まで）
- 勉強ページ数・タイピングスコアを**折れ線／棒グラフ**で見える化 → 努力の積み上げを実感
- ふりかえりの入力で、**日本語の文章力**と**タイピング速度**の練習に

### 日報の入力項目
- **勉強・運動・ゲーム**：それぞれ「＋ふやす」で**何項目でも追加**できます（勉強＝ページ数、運動・ゲーム＝分）
- **プール**：別枠で時間（分）を入力できます
- タイピング（同一条件のスコア）／習い事／ふりかえり（文章）

### TOPページ（やること・気をつけること）
- **やること（もくひょう）**：夏休みの宿題／追加ドリル／プリントの直し／テストの直しなどを並べます。
  「せってい」で **なまえ・たんい・総数** を決められます（総数は空でもOK＝ただの項目になります）。
  日報の「べんきょう」でその名前を選んで数を入れると、**これまでの合計が自動でたまり、残りとバーが動きます**。
- **ぜんぶの すすみぐあい（v1.10.0）**：やることの**いちばん上**に、**総数を入れてある目標を全部合わせた進捗％**を大きく出します。
  - バーの上の**たて線は「夏休みの日にちがどこまで進んだか」**。バーが線より左なら遅れ気味です
  - 日にちより **10ポイント以上おくれる**と黄色に変わって注意が出ます／**100%**で緑になります
  - ⚠ 総数が空の目標は計算に入りません（何ページで終わりか分からないため）。総数つきが1つも無いときは、このまとめ自体が出ません
- **気を つけること**：「言いわけをしない。結果でしめそう」「かならず毎日べんきょうをする」を毎日おさらい

### 🤖 AIコーチ（Claudeせんせい）
日報の下の「**AIに みてもらう**」を押すと、その日の記録を読んで **3つのコメント**（べんきょう／かつどう／ふりかえり）が返ってきます。**1日2回まで**（2回目はふりかえりの文だけ見直します）。

- 見ているのは、その日の記録だけではありません。**しゅくだい全体の進捗％・日にちの進み・きのうまで7日ぶんの記録**も渡しています
- なので「**しゅくだいはまだ◯％、夏休みはもう◯％すぎてる。1日◯ページやれば間に合う**」「**うんどう、ここ◯日してないよね**」のように、数字を根拠にした話ができます
- **ほめるだけではありません**。良い日はしっかりほめ、足りない日ははっきり言います（怒る・けなす・「ダメ」と言うことはしません）
- **ふりかえりの文は小学3年生の目安（3文・60字くらい）**で見ます。短すぎると「もうちょっと書こう」と言われます
  - 🔴 ただし **字数や文の数を口に出すことは禁止**にしてあります（「8文字だよ？」は煽りになるため）。足りないときは「どう思ったかがまだ伝わらないな」のように**中身**で伝えます
- 中身（コーチの言い方）は **`hangar/functions/index.js` の `COACH_STANCE`** に書いてあります。
  ⚠ ここを直したときは **`firebase deploy --only functions:hangar`** が必要です（フロントを出すだけでは変わりません）

> ※「きょうの よみもの」（小3向け読み物）はいったん非表示にしています。復活させたい場合は言ってください（データはコード内に残してあります）。

### 六角形ステータス（せいせきページのメイン）
`漢字・算数・ゲーム・運動・習い事・タイピング` のレーダーチャートです。
能力の正確な計測はむずかしいので、**記録した日数がのびるほど自動でレベルアップ**する仕組みにしています。

- **ゲームと算数は伸びやすく**、**漢字はあとからじっくり伸びる（後追い）**ようにカーブを分けています
- 実際に記録した内容（算数/漢字のページ、運動・プールの時間、タイピングのスコアなど）で、少しだけ上乗せされます
- **写真**を1枚のせられます（作品・自由研究・景色など）。端末に保存（Firebase設定時はクラウドにも同期）

## 6. データのバックアップ

「せってい → バックアップ」から、
- **書き出す**：記録をファイル（.json）に保存
- **よみこむ**：保存したファイルから復元

パソコンを買い替えるときや、念のための保険に使ってください。
